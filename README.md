# شبکه مولد تخاصمی (GAN) برای تولید تصویر کشتی 🚢

پروژه‌ای برای آموزش یک شبکه‌ی مولد تخاصمی از نوع DCGAN با Keras/TensorFlow که تصاویر ۳۲×۳۲ شبیه کشتی و قایق تولید می‌کند.

---

## درباره پروژه

شبکه‌ی مولد تخاصمی (GAN) از دو شبکه‌ی عصبی تشکیل شده که با هم رقابت می‌کنند:

- **مولد (Generator):** از یک بردار نویز تصادفی ۱۰۰تایی یک تصویر می‌سازد.
- **تمییزدهنده (Discriminator):** تصمیم می‌گیرد تصویری که می‌بیند واقعی است (از دیتاست) یا جعلی (ساخته‌ی مولد).

مولد سعی می‌کند تمییزدهنده را فریب بدهد و تمییزدهنده سعی می‌کند فریب نخورد. این رقابت باعث می‌شود مولد کم‌کم تصاویری بسازد که از نظر آماری به تصاویر واقعی شبیه باشند. در این پروژه بدون هیچ برچسب یا شرطی (unconditional) فقط تصاویر کلاس «کشتی» از CIFAR-10 استفاده شده است.

---

## ویژگی‌های پروژه

- معماری DCGAN بدون BatchNormalization (دلیلش در بخش «تجربه‌های آموزشی» آمده)
- Label smoothing برای پایدارتر شدن آموزش
- گزارش معیارهای تشخیصی هر ۱۰ گام: دقت واقعی discriminator و تنوع خروجی مولد (برای تشخیص mode collapse)
- ذخیره‌ی تصاویر پیشرفت به‌صورت ۱۰تایی در یک فایل واحد
- چک‌پوینت‌گذاری شماره‌دار و قابلیت ادامه‌ی آموزش بعد از Restart کرنل

---

## داده

- **دیتاست:** CIFAR-10 (به‌صورت خودکار با `keras.datasets.cifar10` دانلود و کش می‌شود)
- **کلاس انتخابی:** شماره‌ی ۸ (کشتی)، حدود ۵۰۰۰ تصویر
- **پیش‌پردازش:** نرمال‌سازی پیکسل‌ها به بازه‌ی `[-1, 1]` (چون لایه‌ی آخر مولد `tanh` است)

---

## معماری

### مولد (Generator)

| لایه | خروجی |
|---|---|
| ورودی: بردار نویز | ۱۰۰ |
| Dense + LeakyReLU(0.2) | ۸×۸×۱۲۸ (بعد از Reshape) |
| Conv2DTranspose(128, k=4, s=2) + LeakyReLU | ۱۶×۱۶×۱۲۸ |
| Conv2DTranspose(256, k=4, s=2) + LeakyReLU | ۳۲×۳۲×۲۵۶ |
| Conv2D(3, k=5) + tanh | ۳۲×۳۲×۳ |

### تمییزدهنده (Discriminator)

| لایه | خروجی |
|---|---|
| ورودی: تصویر | ۳۲×۳۲×۳ |
| Conv2D(64, k=4, s=2) + LeakyReLU(0.2) | ۱۶×۱۶×۶۴ |
| Conv2D(128, k=4, s=2) + LeakyReLU(0.2) | ۸×۸×۱۲۸ |
| Conv2D(128, k=4, s=2) + LeakyReLU(0.2) | ۴×۴×۱۲۸ |
| Flatten + Dropout(0.3) + Dense(1, sigmoid) | ۱ |

تعداد پارامترها تقریباً ۱٫۶ میلیون برای مولد و ۰٫۴ میلیون برای تمییزدهنده است (محاسبه‌شده از معماری بالا).

## نحوه‌ی آموزش

- **تابع هزینه:** `binary_crossentropy`
- **بهینه‌ساز:** Adam با نرخ یادگیری `0.0002` و `beta_1 = 0.5` برای هر دو شبکه
- **اندازه‌ی batch:** ۳۲
- **تعداد گام‌ها:** تا ۱۵۰۰۰. توجه کنید که «epoch» در این پروژه یک گام (یک batch) است، نه یک دور کامل روی دیتاست.
- **هر گام:**
  1. یک batch تصویر واقعی و یک batch تصویر جعلی (جدا از هم) به discriminator داده می‌شود.
  2. با شبکه‌ی ترکیبی (مولد + discriminator فریز‌شده) و برچسب «واقعی»، مولد یک‌بار به‌روزرسانی می‌شود.
- **Label smoothing:** برچسب‌های واقعی بین `0.9` و `1.0` و برچسب‌های جعلی بین `0.0` و `0.1` نمونه‌برداری می‌شوند.
- **چک‌پوینت:** هر ۱۰۰ گام، هم با شماره‌ی گام (`checkpoints/generator_epoch{N}.weights.h5`) و هم با نام ثابت برای ادامه‌ی آموزش

### خواندن لاگ آموزش

```
epoch 6200: d_loss=0.7007 g_loss=0.7839 | real_acc=0.62 fake_acc=0.81 | diversity=0.394
```

- `d_loss` و `g_loss` نزدیک به حدود `0.69` (یعنی `ln 2`) نشان‌دهنده‌ی تعادل است: discriminator نه خیلی مطمئن است و نه کاملاً گیج.
- `real_acc` و `fake_acc` دقت واقعی discriminator هستند که جدا و بدون label smoothing محاسبه می‌شوند.
- `diversity` میانگین انحراف معیار پیکسل‌ها بین ۱۶ تصویر تولیدشده است. اگر نزدیک صفر شود، مولد به یک خروجی ثابت رسیده (mode collapse).

---

## نتایج

- حدود گام ۶۰۰۰ تصاویر کشتی و قایق قابل‌تشخیص با آسمان، آب و بدنه‌ی مشخص تولید می‌شوند و بین نمونه‌ها تنوع خوبی وجود دارد.
- بین گام‌های ۱۰۰۰۰ تا ۱۱۳۰۰ پیشرفت محسوسی دیده نشد (مقایسه‌ی چشمی با نویز ثابت).
- در این بازه: `d_loss` حدود `0.63` تا `0.72`، `g_loss` حدود `0.71` تا `0.96`، و `diversity` حدود `0.36` تا `0.51` بود. هیچ نشانه‌ای از mode collapse یا واگرایی دیده نشد.
- جزئیات ریز (دکل‌ها و لبه‌ها) تار است. این برای رزولوشن ۳۲×۳۲ و حدود ۵۰۰۰ تصویر آموزشی انتظار می‌رود.

## تجربه‌های آموزشی

مواردی که در طول توسعه مشاهده شد و می‌تواند برای پروژه‌های مشابه مفید باشد:

1. **`clipnorm=1.0` آموزش را متوقف کرد.** با این تنظیم هر دو loss از همان ابتدا روی `0.0000` ماند و هیچ یادگیری‌ای رخ نداد. حذف آن مشکل را حل کرد.
2. **نسخه‌ی اولیه با BatchNormalization در هر دو شبکه هرگز تصویر کشتی نساخت.** تا حدود گام ۹۰۰۰ خروجی‌ها نویز با رنگ‌های اشباع‌شده و تقریباً یکسان بودند (mode collapse). بعد از حذف BatchNorm و استفاده از معماری بالا (مثل DCGAN کتاب Deep Learning with Python)، تصاویر قابل‌تشخیص شدند. توضیح احتمالی این است که BatchNorm در مدل ترکیبی (با discriminator فریز‌شده) و در آموزش مستقیم discriminator رفتار متفاوتی دارد؛ این توضیح با آزمایش مستقیم تأیید نشده و فقط یک فرضیه است.
3. **متریک `accuracy` با label smoothing گمراه‌کننده است** (چون برچسب‌ها اعشاری‌اند، دقت همیشه ۰ نشان داده می‌شد). برای همین دقت واقعی جداگانه محاسبه می‌شود.
4. **همیشه چک‌پوینت شماره‌دار نگه دارید.** در یک GAN ممکن است مدل بعد از یک نقطه‌ی خوب collapse کند. اگر فقط یک فایل مدام بازنویسی شود، نقطه‌ی خوب از دست می‌رود.
5. **با loss نمی‌شود کیفیت را قضاوت کرد.** `d_loss` و `g_loss` ممکن است سالم به‌نظر برسند در حالی که تصاویر نویز هستند. حتماً تصاویر نمونه را هم ببینید.

## نحوه اجرا

۱. فایل `image_gan_v3.ipynb` را باز کنید و سلول‌ها را به ترتیب اجرا کنید.

۲. **ادامه‌ی آموزش:** اگر فایل‌های `generator.weights.h5`، `discriminator.weights.h5` و `gan_training_progress.json` کنار notebook باشند، آموزش از آخرین گام ذخیره‌شده ادامه پیدا می‌کند. برای شروع از صفر، این سه فایل (و پوشه‌ی `checkpoints`) را قبلش به یک پوشه‌ی پشتیبان منتقل کنید.

۳. **تولید تصویر با مدل ذخیره‌شده:**

```python
import numpy as np
import matplotlib.pyplot as plt
from keras.models import load_model

generator = load_model("generator_best.h5", compile=False)
noise = np.random.normal(0, 1, (16, 100))
imgs = np.clip(0.5 * generator.predict(noise, verbose=0) + 0.5, 0, 1)

fig, axs = plt.subplots(4, 4, figsize=(6, 6))
for k, ax in enumerate(axs.flat):
    ax.imshow(imgs[k])
    ax.axis("off")
plt.show()
```
